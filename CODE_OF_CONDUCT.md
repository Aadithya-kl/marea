# Code of Conduct

Marea is a small project and wants to stay a friendly one.

- Be respectful and assume good intent. Critique ideas and code, not people.
- No harassment, insults, discrimination or unwelcome attention, in any space of the project.
- Keep discussions on topic and in a language others can follow (English is the default; other
  languages are welcome in translation work).
- Protect privacy: don't post other people's personal data, and strip your own paths from logs
  you don't want to share.

Maintainers may edit or remove contributions and block participants who break these rules.
Report problems privately to the maintainers through GitHub (profile contact or a private
security advisory if it involves a vulnerability).

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
